🐛 TROUBLESHOOTING:
================================================================================

ISSUE: "No module named 'reportlab'"
FIX: pip install reportlab

ISSUE: "Cannot find metrics file"
FIX: Run evaluation first: python main.py --evaluate

ISSUE: "Charts not appearing in report"
FIX: 
  1. Check charts exist in outputs/plots/evaluation/
  2. Run: python main.py --evaluate (to generate charts)
  3. Regenerate report

ISSUE: "PDF won't open / corrupted"
FIX:
  1. Check for errors during generation
  2. Ensure reportlab is up to date: pip install --upgrade reportlab
  3. Check disk space

ISSUE: "Custom styling not working"
FIX:
  1. Verify paragraph style names are correct
  2. Check color hex codes are valid
  3. Ensure font names are recognized

ISSUE: "Report generation is slow"
FIX:
  • This is normal for reports with many charts
  • Each embedded image takes time to process
  • Use include_charts=False for faster generation (text only)
