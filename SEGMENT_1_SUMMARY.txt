METHOD 1: QUICK SETUP (Your Machine)
-------------------------------------
1. Navigate to project directory:
   cd /path/to/water_contamination_early_warning_system

2. Create virtual environment (recommended):
   python -m venv venv
   
   # Activate it:
   Windows: venv\Scripts\activate
   Linux/Mac: source venv/bin/activate

   pip install --upgrade pip
   pip install -r requirements.txt

4. Verify setup:
   python verify_setup.py

5. Expected output:
   ✓ Python 3.8+
   ✓ All packages installed

❓ TROUBLESHOOTING:
================================================================================

Q: verify_setup.py shows missing packages
A: Run: pip install -r requirements.txt

Q: TensorFlow installation fails
A: For CPU only: pip install tensorflow-cpu
   For GPU: Ensure CUDA 11.8 is installed

Q: Out of disk space
A: Project requires ~2GB for models + outputs

Q: Permission denied errors
A: Run with appropriate permissions or change directory ownership

Q: Can't find datasets
A: Ensure files are in data/raw/ (case-sensitive!)
