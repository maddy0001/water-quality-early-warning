🚀 HOW TO RUN THE DASHBOARD:
================================================================================

OPTION 1: Using Launch Scripts (Easiest)
─────────────────────────────────────────

Windows:
  1. Double-click: run_dashboard.bat
  2. Dashboard opens automatically in browser
  3. That's it!

Linux/Mac:
  1. Make executable: chmod +x run_dashboard.sh
  2. Run: ./run_dashboard.sh
  3. Dashboard opens automatically in browser

OPTION 2: Manual Launch
────────────────────────

1. Install dashboard dependencies:
   pip install -r dashboard/requirements_dashboard.txt

2. Run Streamlit:
   streamlit run dashboard/app.py

3. Opens at: http://localhost:8501

📊 SAMPLE USAGE:
================================================================================

SCENARIO 1: Check Single Sample
────────────────────────────────
1. Go to "🔍 Classification" page
2. Select "📝 Manual Entry"
3. Enter 9 water quality parameters:
   - pH: 7.2
   - Hardness: 180.5
   - Solids: 15000
   - Chloramines: 6.8
   - Sulfate: 250
   - Conductivity: 420
   - Organic Carbon: 12.5
   - Trihalomethanes: 60
   - Turbidity: 3.2
4. Click "🔍 Classify Water Sample"
5. See instant alert: NORMAL/LOW/MEDIUM/CRITICAL

SCENARIO 2: Batch Analysis
───────────────────────────
1. Prepare CSV with columns:
   ph, Hardness, Solids, Chloramines, Sulfate,
   Conductivity, Organic_carbon, Trihalomethanes, Turbidity
2. Go to "🔍 Classification" page
3. Select "📁 Upload CSV File"
4. Upload your CSV
5. Click "🔍 Classify All Samples"
6. See batch results with charts
7. Download results CSV

SCENARIO 3: View Alert History
───────────────────────────────
1. Go to "🚨 Alert History" page
2. Select time range
3. Filter by alert levels
4. See timeline and location analysis
5. Export historical data
