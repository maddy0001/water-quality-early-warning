================================================================================
🎯 EXECUTION MODES:
================================================================================

MODE 1: --full (Complete System)
────────────────────────────────
Runs all 5 pipelines in sequence:
  [1/5] Classification     → Train RF, XGBoost, SVM, Ensemble
  [2/5] Forecasting        → Train BiLSTM, GRU
  [3/5] Anomaly Detection  → Train IF, LOF, OCSVM, Autoencoder
  [4/5] Explainability     → SHAP analysis, feature importance
  [5/5] Evaluation         → Generate 16+ plots, metrics

Time: 30-45 minutes (CPU), 15-20 minutes (GPU)
Output: Everything (models + plots + metrics)

MODE 2: --train (Models Only)
──────────────────────────────
Trains and saves all models without evaluation:
  • Classification models
  • Forecasting models
  • Anomaly detectors

Time: 15-20 minutes
Output: Trained models in models/

MODE 3: --evaluate (Plots Only)
────────────────────────────────
Uses existing models to generate visualizations:
  • 16 evaluation plots
  • LaTeX tables
  • Metrics JSON

Time: 30 seconds
Output: Plots in outputs/plots/evaluation/

MODE 4: --demo (Early Warning Demo)
────────────────────────────────────
Runs early warning system on sample data:
  • Monitors N water samples (default: 50)
  • Generates alerts
  • Shows risk score
  • Demonstrates real-time capability

Time: 1-2 minutes
Output: Alert statistics, demo results

MODE 5: --info (System Info)
─────────────────────────────
Displays system information:
  • Python package versions
  • GPU availability
  • Dependency status
  • Configuration settings

Time: Instant
Output: System details

SYSTEM OVERVIEW:
"A comprehensive AI-powered early warning system for water quality monitoring
was developed, integrating classification, time series forecasting, and 
anomaly detection models. The system provides real-time contamination alerts
through a 4-level warning mechanism."

METHODOLOGY:
"The system employs an ensemble approach combining:
- Classification: Random Forest, XGBoost, SVM with soft voting
- Forecasting: BiLSTM and GRU with attention mechanisms
- Anomaly Detection: Isolation Forest, LOF, One-Class SVM, Autoencoder
- Alert Aggregation: Weighted voting (40/30/30) from subsystems"

KEY RESULTS:
- Classification: 73.2% accuracy, 78.9% ROC-AUC (Ensemble)

- Anomaly Detection: F1=90.9% (Ensemble voting)
- Real-time: <50ms per sample
