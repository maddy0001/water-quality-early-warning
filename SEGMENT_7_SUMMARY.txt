================================================================================
🧠 KEY CONCEPTS:
================================================================================

**SHAP (Shapley Values):**
  - Game theory approach to feature attribution
  - Fair allocation of prediction "credit" to features
  - Both global (overall importance) and local (per-prediction)

**Tree Importance:**
  - Based on information gain in tree splits
  - Fast, built-in to Random Forest/XGBoost
  - May bias toward high-cardinality features

**Permutation Importance:**
  - Measures accuracy drop when feature is shuffled
  - Model-agnostic, works for any model
  - More reliable but slower to compute

**Why Use All Three?**
  - Cross-validation of feature importance
  - Different perspectives on feature relevance
  - Robust to method-specific biases
