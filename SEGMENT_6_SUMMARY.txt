🧠 HOW EACH DETECTOR WORKS:
================================================================================

1. ISOLATION FOREST
───────────────────
How: Randomly partitions data space using trees
     Anomalies are easier to isolate → shorter tree paths
     
Strengths:
  ✓ Fast, scalable
  ✓ Works well in high dimensions
  ✓ No assumptions about data distribution
  
Best for: Rare contamination events with unusual feature combinations

Parameters:
  - n_estimators: 100 trees
  - contamination: 0.05 (expects 5% anomalies)
  - max_features: 1.0 (uses all features)

2. LOF (LOCAL OUTLIER FACTOR)
──────────────────────────────
How: Compares local density of each point with its neighbors
     Points in sparse regions = outliers
     
Strengths:
  ✓ Detects local density deviations
  ✓ Good for clustered normal data
  ✓ Robust to varying densities
  
Best for: Contamination events that create isolated data points

Parameters:
  - n_neighbors: 20 (neighborhood size)
  - contamination: 0.05

3. ONE-CLASS SVM
────────────────
How: Learns a tight boundary around normal data
     Points outside boundary = anomalies
     Uses RBF kernel for non-linear separation
     
Strengths:
  ✓ Strong theoretical foundation
  ✓ Works well for bounded normal regions
  ✓ Effective in high dimensions
  
Best for: Data with clear normal operating envelope

Parameters:
  - kernel: RBF (radial basis function)
  - nu: 0.05 (upper bound on anomaly fraction)
  - gamma: 'scale'

4. AUTOENCODER (DEEP LEARNING)
───────────────────────────────
How: Neural network learns to reconstruct normal data
     High reconstruction error = anomaly
     
Architecture: Input(9) → Dense(16) → Encoding(8) → Dense(16) → Output(9)
     
Strengths:
  ✓ Captures complex non-linear patterns
  ✓ Learns optimal features automatically
  ✓ Excellent for subtle anomalies
  
Best for: Complex, multi-feature contamination patterns

Parameters:
  - encoding_dim: 8 (compressed representation)
  - epochs: 100 (with early stopping)
  - threshold: 95th percentile of training error

5. ENSEMBLE (VOTING)
────────────────────
How: Runs all 4 detectors independently
     Combines predictions via voting
     Default: if ≥2 detectors flag → anomaly
     
Strengths:
  ✓ More robust than any single detector
  ✓ Reduces false positives
  ✓ Catches different types of anomalies
  
Configuration:
  - voting_threshold: 0.5 (50% of detectors must agree)

"4. Anomaly Detection

A multi-algorithm ensemble approach was employed to detect contamination 
events and water quality anomalies. Four complementary detection methods 
were integrated:

1. Isolation Forest: Tree-based partitioning identifies samples requiring
   fewer splits for isolation (anomalies have shorter path lengths).

2. Local Outlier Factor (LOF): Density-based approach compares local 
   density with k-nearest neighbors. Points in sparse regions indicate 
   potential contamination.

3. One-Class SVM: Learns a decision boundary around normal water quality 
   patterns using RBF kernel. Samples outside this boundary are flagged.

4. Autoencoder: Deep neural network (9→16→8→16→9 architecture) reconstructs 
   normal samples with low error. High reconstruction error signals anomaly.

Ensemble Strategy:
The four detectors operate independently, each voting on whether a sample 
is anomalous. A sample is classified as contaminated if at least 50% of 
detectors (≥2 out of 4) flag it. This voting mechanism reduces false 
positives while maintaining high sensitivity.

Configuration:
- Isolation Forest: 100 estimators, contamination=0.05
- LOF: k=20 neighbors, contamination=0.05
- One-Class SVM: RBF kernel, ν=0.05
- Autoencoder: encoding_dim=8, 95th percentile threshold
